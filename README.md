# Butemba Modern Nursery and Primary School

A modern, responsive school website built with HTML, CSS, and JavaScript.

## Included
- Homepage hero section
- About section
- Programs overview
- School values
- Contact section with phone, email and address
- Responsive mobile navigation
- Cream and navy blue branding

## GitHub Pages
This project is ready to be deployed to GitHub Pages.

1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Select the `main` branch and the root folder.
4. Save.

Your live website URL will be:
https://givinghand2010.github.io/modern-business-website/
